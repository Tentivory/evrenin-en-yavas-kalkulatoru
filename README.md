# Evrenin En Yavaş Kalkülatörü

## Giriş

Bu proje, insanlığın bildiği en yavaş çalışan hesap makinesini sunar. 2 + 2 işlemi ortalama 47 yıl sürer. Bu, tamamen bilimsel bir başarıdır (kanıtlar uydurmadır).

## Özellikler

- **Aşırı Yavaşlık**: Her işlemde yıldızlara danışır, çay demler, kedi uyandırır.
- **Bilimsel Doğruluk**: Sonuçlar %100 doğrudur, sadece çok geç gelir.
- **Türkçe Destek**: Tüm mesajlar aşırı ciddi Türkçe ile yazılmıştır.
- **Sonsuz Bekleme Garantisi**: Hata durumunda bile çay içmeye gider.

## Kullanım

```bash
python yavas_kalkulator.py
```
